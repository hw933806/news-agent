# CPNG — Sources (raw, local-only)

Drop **any** raw diligence file for CPNG here: memos, Excel models, expert-call
PDFs/transcripts, screenshots, filings. Then run the ingest flow (see `INGEST.md`
at the repo root, or just tell Claude "ingest the new CPNG files").

**These raw files are git-ignored on purpose** — this repo is PUBLIC (the daily
news routine clones it with no creds). Only the *synthesized* markdown that ingest
produces — `knowledge.md` and any `thesis.md` edits — gets committed. This README
is the one tracked file in here so the folder always exists.
